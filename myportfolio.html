STATEMENT OF PURPOSE

> สารสนเทศจะไหวหรอ? แรงบันดาลใจ? ทำไมต้องมจธ.?

ผมชื่อนายธนโชค ฉิมมาลีที่สนใจการใช้คอมพิวเตอร์ตั้งแต่เด็ก โดยเริ่มจากการใช้คอมพิวเตอร์ของพี่ชายช่วงประถมศึกษาผ่านการเล่นเกม Roblox จึงเกิดแรงบันดาลใจในการสร้างแมพด้วยตนเองจากการศึกษายูทูบ ในช่วงมัธยมต้นผมได้เริ่มเขียนโปรแกรมด้วยภาษา Python ทำให้รู้ว่าตนเองชอบในการในการเขียนโค้ดและผมอยากเปลี่ยนแปลง ความรู้ด้านคอมพิวเตอร์ให้เป็นโอกาสในเส้นทางอนาคตของตัวเอง

ผมที่เป็นเด็กพุทธบูชา native จึงรู้จักมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี เพราะอยู่ใกล้บ้านและเป็นมหาวิทยาลัยชั้นนำ ในช่วงมัธยมปลาย ผมได้นำภาษา C มาประยุกต์ใช้กับบอร์ดไมโครคอนโทรลเลอร์ซึ่งทำให้ผมชอบการในลงมือทำจริง ซึ่งตรงกับมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรีที่เด่นด้านเทคโนโลยีและที่ไม่เพียงทฤษฎี แต่ยังให้ความสำคัญกับการลงมือปฏิบัติจริง

การเข้าร่วมกิจกรรมอย่างค่าย SIT CAMP ได้ช่วยเปิดโลกการสร้างเว็บไซต์ให้ผมได้เรียนรู้การใช้งานภาษา HTML, CSS และ JavaScript ร่วมกับการใช้งาน Visual Studio Code และทำโปรเจกต์นำเสนอช่วยฝึกฝนทักษะการแก้ปัญหาเฉพาะหน้าเมื่อ error ฝึกการทำงานร่วมกับผู้อื่นภายใต้แรงกดดันข้อจำกัดของเวลาโดยการไม่รู้จักกันมาก่อน ฝึกการปรับตัวเข้ากับสภาพแวดล้อมที่ท้าทายขนาดกรรมการถามคำถาม ซึ่งทำให้ผมสนใจในคณะเทคโนโลยีสารสนเทศ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี

เป้าหมายในอนาคต สามารถทำงานโดยมีความพร้อมในการปฏิบัติงานได้จริง นำประสบการณ์ฝั่งเทคโนโลยีที่เรียนรู้มาพัฒนาและสร้างนวัตกรรมที่ตอบโจทย์ผู้ใช้งาน พัฒนาตัวเองโดยใช้ปัญญาประดิษฐ์เป็นเครื่องมือสนับสนุน และร่วมเป็นส่วนหนึ่งในของครอบครัว SIT KMUTT เพื่อก้าวไปสู่เป้าหมายสายการทำงานที่ตั้งใจไว้
